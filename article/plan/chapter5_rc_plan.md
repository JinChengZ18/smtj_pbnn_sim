# 第五章 基于 sMTJ 的储备池计算：硬件评估与器件优化指导（规划）

本章在前两章 sMTJ 器件模型（第二章）与 PBNN 硬件仿真器（第四章）的基础上，
探讨同一颗已校准的 sMTJ 器件能否承担一种与概率推理正交的计算范式——储备池
计算（Reservoir Computing, RC）。本文为该章的规划文档：先论证物理可行性并给出
原型验证结果，再梳理既有自旋电子 RC 工作的能力边界与本章空白点，提出仿真器需要
补齐的扩展，最后给出以**硬件评估**与**器件优化指导**为重点的实验套件与验证策略。

## 5.1 动机：从"无记忆 p-bit"到"有记忆动力学节点"

第四章的 PBNN 把 sMTJ 用作一个**可控随机数发生器**：采样路径
（`sampling/bernoulli_smtj.py` 与 `sampling/unfold.py`）每次独立抽取
Bernoulli 样本并对 T 次取平均，刻意抹去样本间的时间相关，以无偏估计期望
$\sigma(\theta)$。这与第二章 `psw_neel_brown` 给出的"给定脉冲 $t_p$、翻转概率"
一脉相承——它是一次性的、**无记忆**的写概率。

储备池计算的需求恰好相反。RC 需要一个固定（不训练）的高维非线性动力学系统，
具备**衰减记忆**（fading memory / echo-state property）：当前状态依赖近期输入
历史而渐忘远期。只训练一个线性读出层。其核心要件是一个带弛豫时间常数的有状态
系统。

超顺磁 sMTJ 在物理上天然满足这一要件。磁矩在双势阱间随机翻转（随机电报噪声，
RTN），构成一个两态连续时间马尔可夫过程；偏置电压倾斜势阱、改变两个逃逸势垒。
沿用第二章的 Néel-Brown 激活律，两个逃逸速率为

$$
r_\uparrow(V) = \frac{1}{\tau_0}\exp\!\big[-\Delta(1 - V/V_{c0})\big],\qquad
r_\downarrow(V) = \frac{1}{\tau_0}\exp\!\big[-\Delta(1 + V/V_{c0})\big],
$$

其中 $r_\uparrow$ 恰为第二章的 NB 速率（本章在 `device/arrhenius.py` 中新增
`neel_brown_rate` 将其单独暴露），$r_\downarrow$ 是偏置反向的同一律。由此闭式
导出 RC 关心的两个量：

* **稳态均值（输入→状态的非线性）**
  $\langle s\rangle_\infty(V) = (r_\uparrow - r_\downarrow)/(r_\uparrow + r_\downarrow)
  = \tanh(\Delta V / V_{c0})$，零偏斜率 $\Delta/V_{c0}\approx 5.7\,\mathrm{V^{-1}}$；
* **弛豫（相关）时间——即衰减记忆**
  $\tau(V) = 1/(r_\uparrow + r_\downarrow)$，在 $V=0$ 处取极大
  $\tau_\mathrm{max} = \tau_0 e^{\Delta}/2$（第二章 Device-A 参数 $\Delta=4.91$、
  $\tau_0=1\,\mathrm{ns}$ 给出约 68 ns），随驱动增大而向 $\tau_0$ 收缩。

因此偏置电压同时是输入注入口、记忆长度旋钮与非线性强度旋钮：小 $|V|$ 长记忆、
大 $|V|$ 强非线性饱和，这正是 RC 经典的**记忆—非线性权衡**，在此被一个有物理
意义的器件参数所参数化。

**原型验证（实验 14）。** 本章已实现该路径的最小可行原型并验证其可计算性：

* 设备层 `device/telegraph.py`：两态 CTMC 的精确传播子，按任意步长 `dt` 演化；
* 储备池层 `reservoir/`：群体节点 + 可选谱半径标定的递归耦合 + 集成平均读出，
  附噪声无关的 mean-field 参照模式（类比 PBNN 的 `software` 模式）；
* 结果：mean-field（理想）记忆容量 MC$\approx$6.6、NARMA-10 NRMSE$\approx$0.61；
  真实采样（每节点 96 器件集成）MC$\approx$2.0、NARMA-10 NRMSE$\approx$0.81。

原型既证明"sMTJ 动力学足以支撑 RC"，又暴露了核心硬件问题：**有限器件集成下的
散粒噪声是 sMTJ-RC 的首要限制**，且记忆深度与信噪比之间存在经由 `dt/τ` 的权衡。
这两点正是本章硬件评估与器件优化指导的出发点。

## 5.2 既有自旋电子 RC 工作的能力边界

为定位本章，对相关 RC 仿真/实现作一次梳理，可分四簇，各自相对"超顺磁
sMTJ-RC + 端到端硬件评估"这一目标有明确缺口。

### 5.2.1 自旋力矩纳米振荡器（STO）储备池

Torrejon 等人 2017 年在 *Nature* 上以单个自旋力矩纳米振荡器配合时分复用虚拟
节点，完成口语数字识别[^sto_torrejon]；后续工作扩展到耦合振荡器阵列与频域多
路复用[^sto_coupled]。Grollier 等人的综述系统总结了自旋电子神经形态计算的器件
谱系[^spintronic_review]。这一簇的动力学来源是**振荡器的非线性瞬态与相位**，
器件是确定性（含少量热噪声）的连续相位系统，与超顺磁器件的**随机两态翻转**在
物理机制、噪声结构与读出方式上都不同。

### 5.2.2 超顺磁/随机 MTJ 的概率计算

Camsari、Borders、Sutton 等人将低势垒 sMTJ 用作 p-bit，构建概率自旋逻辑、整数
分解与模拟退火[^psl_camsari][^borders_factorize][^sutton_coprocess]；Kaiser 等人
实现基于 sMTJ 的原位玻尔兹曼机学习[^kaiser_insitu_bm]（第四章已引为最近先例）。
这些工作与本章共享器件，但任务是**无向图模型的采样/优化**（Gibbs 更新、能量
最小化），并不利用衰减记忆，也不做时间序列处理。

### 5.2.3 其他介质的储备池

忆阻器/原子开关网络[^memristor_rc]、光子腔与延迟反馈[^photonic_rc]、自旋波
[^spinwave_rc] 等均有 RC 实现，分别在各自介质内成熟，但器件物理、能耗模型与
本工作不通用，无法直接借用其 PPA 结论。

### 5.2.4 综合判断与本章定位

将上述对照本章目标——以第二章已校准的 sMTJ 写概率模型为入口，把同一器件复用为
RC 的随机两态动力学节点，并在第四章的分层仿真器内做端到端的 PPA 硬件评估与器件
优化指导——可见没有既有工具落在该交集：STO-RC 的器件不是超顺磁随机翻转；p-bit
工作不做时序记忆任务；其他介质的硬件模型不通用。因此本章复用第四章已成熟的器件
校准、变异、阵列与 PPA 估算成果，仅在"有状态器件演化层"与"储备池/读出层"独立
实现，恰好匹配 sMTJ-RC 的语义。

## 5.3 仿真器扩展：已建与待建

**已建（原型，实验 14）**

| 模块 | 文件 | 作用 |
|---|---|---|
| NB 速率 | `device/arrhenius.py::neel_brown_rate` | 暴露连续时间逃逸速率（复用既有 NB） |
| 电报模型 | `device/telegraph.py` | 两态 CTMC 精确传播子、稳态均值、弛豫时间、群体 |
| 储备池 | `reservoir/node.py` | 群体节点、输入掩码、谱半径标定递归、集成平均、mean-field |
| 读出 | `reservoir/readout.py` | 闭式岭回归（RC 唯一被训练的部分） |
| 任务 | `reservoir/tasks.py` | NARMA-10、记忆容量输入、正弦/方波 |
| 指标 | `reservoir/metrics.py` | NRMSE、线性记忆容量 MC |

**待建（按优先级）**

1. **PPA 扩展（硬件评估核心）。** 在 `ppa/` 下新增 RC 算子粒度的能量/延迟/面积
   分解：单步前向 = 输入 DAC + 器件演化（$V^2/R_\mathrm{SOT}\cdot dt$，复用第二章
   写能量）+ 读出计数累加（复用 `tech_params`）；并接入第四章 `training_energy`
   的多架构对比范式（exp 13），加入"数字 ESN（SRAM/STT-MRAM）"基线。
2. **物理递归耦合。** 用第四章 `array/crossbar.py` 实现节点间的物理耦合矩阵
   （偶极场/共享读出电流线的抽象），替代原型中纯数值的 $W_\mathrm{res}$，评估其
   保真度与面积代价。
3. **时分复用单节点储备池**（Appeltant 式），与群体式做面积—吞吐—精度对比。
4. **变异与缺陷下的 RC。** 复用 `device/variation.py`（$\Delta$ 的 D2D 变异）与
   exp 09 的 bit-flip 范式，评估 RC 读出对器件失配/翻转的鲁棒性。
5. **温度依赖。** 在速率中引入温度项（$\Delta$、$\tau_0$ 的温度标度），把温度
   作为 $\tau$ 的额外旋钮纳入设计空间。
6. **s-LLGS 交叉验证。** 复用 `device/llg_dynamics.py` 骨架并加入热 Wiener 噪声，
   在校准点交叉验证电报模型给出的 $\tau(V)$（仅校验，不进运行路径）。

## 5.4 实验套件（重点：硬件评估 + 器件优化指导）

按第四章 BLRNet/PBNN 实验套件（exp 05–13）的严谨度组织：每个实验单一 YAML 参数化、
产出可复现图表、标注数据来源。分两组。

### A. 硬件评估组

* **exp R1 — PPA 对比。** 同一组时序任务（NARMA-10 + 口语数字）下，sMTJ-RC
  vs 数字 ESN（SRAM-CIM）vs STT-MRAM-ESN vs 第四章 PBNN-MLP 的能量/面积/延迟，
  复用 exp 13 的带文献引用的器件库。回答："把 sMTJ 当动力学节点，相对把它当
  p-bit 或相对全数字 ESN，硬件代价如何。"
* **exp R2 — 群体式 vs 时分复用。** 同精度下两种实现的器件数、面积、吞吐、能量
  权衡。
* **exp R3 — 集成规模三维扫描。** （devices/node, 精度, 能量）——原型 exp 14(f)
  的完整版，量化散粒噪声的硬件成本，给出"达到理想 MC 的 X% 所需的最小集成度"。
* **exp R4 — 变异/缺陷鲁棒性。** D2D 变异与 bit-flip 下的 RC 精度（复用 exp 08/09
  范式），并与 PBNN 的鲁棒性结论对照。

### B. 器件优化指导组（本章独特贡献）

* **exp R5 — 设计空间地图。** 在 $(\Delta, \tau_0, V_{bias})$ 上扫描，绘制
  (记忆容量, 非线性度, 最优任务时间尺度) 的等高线，给出"为 RC 优化的 sMTJ 应
  落在何种势垒/临界电压区间"的定量结论。预期方向：RC 偏好比 PBNN 写操作更低的
  $\Delta$（更接近超顺磁/临界稳定），以获得与输入采样率匹配的 $\tau$。
* **exp R6 — 记忆—非线性权衡前沿。** 由 $V_{bias}$ 与 $dt/\tau$ 扫描得到
  MC（线性记忆）与 IPC 非线性分量之间的 Pareto 前沿，定位器件的最佳工作点。
* **exp R7 — 时间尺度匹配律。** $\tau(V, T)$（含温度）与输入采样周期的匹配关系，
  给出"给定任务时标，应如何选 $\Delta$/偏置/温度"的设计公式。
* **exp R8 — 面向 RC 的器件定制建议。** 综合 R5–R7，对比"为 RC 定制"（低 $\Delta$
  超顺磁、$\tau$ 落在 10–100 ns）与第二章"为 PBNN/MRAM 定制"（高 $\Delta$ 稳态
  保持）的器件参数差异，回连第二章的器件设计，形成可交给工艺/器件同事的指导。

**基准任务库。** NARMA-10、Mackey-Glass 与 Santa Fe 激光（预测）、线性记忆容量
MC 与信息处理容量 IPC（记忆/非线性分解）、temporal-XOR/parity（非线性记忆）、
正弦/方波分类、（可选）口语数字 TI-46 子集。

## 5.5 验证策略与小节安排

* **正确性。** 已有 27 个单元测试（`tests/test_telegraph.py`、
  `tests/test_reservoir.py`）锚定：稳态均值收敛到 $\tanh(\Delta V/V_{c0})$、
  $\tau(0)=\tau_0 e^{\Delta}/2$、上行速率等于 `neel_brown_rate`、岭回归恢复线性
  映射、mean-field 储备池 MC$>1$。
* **理想参照。** mean-field 模式作为噪声无关上界，任何随机结果都对照它解读。
* **物理交叉验证。** 以 s-LLGS（加热噪声）在校准点核对 $\tau(V)$。
* **小节安排。** 5.1 动机与物理基础 / 5.2 既有工作 / 5.3 仿真器扩展 / 5.4 设备层

## 5.6 风险与开放问题

* **散粒噪声 vs 面积。** 集成平均是直接但费面积的降噪手段；是否存在更省的读出
  （延长读出窗口的速率读出、时间平均、或在概率域而非翻转域读出）需在 R3 中评估，
  这关系到 sMTJ-RC 能否在 PPA 上胜过数字 ESN。
* **物理递归耦合的保真度。** 偶极/电流耦合能否实现接近理想 $W_\mathrm{res}$ 的谱
  特性，是群体式方案可行性的关键。
* **随机性的价值需诚实评估。** 与确定性 ESN 相比，器件随机性更可能是代价而非
  优势；本章应明确区分 sMTJ-RC 真正占优的指标（如能量、面积、对偏置漂移的鲁棒
  性）与不占优的指标，避免过度宣称。可能的结论是"在特定时标/能量预算下有利"，
  而非全面超越。
